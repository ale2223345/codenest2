Cursos & Portafolio

Rutas de aprendizaje diseñadas con base en la demanda real de la industria del software.

Rutas de Aprendizaje

Portafolio de Cursos Formativos

Cada curso culmina con proyectos tangibles para incorporar inmediatamente en tu portafolio profesional.

1. Fundamentos de la Programación

Ideal para personas que inician desde cero. Aprende lógica algorítmica, resolución de problemas y estructuras de datos elementales.

  • Duración: 8 semanas
  • Modalidad: 100% Online
  • Proyecto: Aplicación de consola en Python/JS
Solicitar Información

2. Desarrollo Web Front-End

Maqueta interfaces modernas, accesibles y responsivas implementando HTML5 semántico, CSS3 avanzado, Bootstrap 5 y JavaScript dinámico.

  • Duración: 12 semanas
  • Modalidad: Online con mentorías
  • Proyecto: Sitio web interactivo responsive
Solicitar Información

3. Desarrollo Web Back-End

Crea servidores robustos, APIs REST seguras y maneja la lógica de negocio utilizando Node.js, Express y autenticación de usuarios.

  • Duración: 12 semanas
  • Modalidad: Online práctica
  • Proyecto: API REST funcional autenticada
Solicitar Información

4. Desarrollo Full Stack

El programa más completo: conecta la experiencia de usuario del frontend con el backend y bases de datos en aplicaciones web integrales.

  • Duración: 16 semanas
  • Modalidad: Online intensivo
  • Proyecto: Plataforma web full-stack desplegada
Solicitar Información

5. Bases de Datos y SQL

Domina el diseño conceptual, modelado relacional y consultas complejas en PostgreSQL y MySQL para gestionar información empresarial.

  • Duración: 8 semanas
  • Modalidad: 100% Online
  • Proyecto: Modelo relacional y consultas analíticas
Solicitar Información

6. Introducción a Aplicaciones

Aprende las bases de las arquitecturas de software modernas y el desarrollo de interfaces móviles multiplataforma para Android y la web.

  • Duración: 10 semanas
  • Modalidad: Online guiada
  • Proyecto: Prototipo de aplicación funcional
Solicitar Información

7. Diseño UX/UI para la Web

Diseña interfaces centradas en el usuario: investigación, wireframes, prototipos en Figma y criterios de accesibilidad.

  • Duración: 10 semanas
  • Modalidad: Online con mentorías
  • Proyecto: Prototipo navegable de un sitio web
Ver detalles Información

8. Git, GitHub y Despliegue Web

Aprende control de versiones, trabajo en equipo con ramas y pull requests, y publica tus proyectos en hosting gratuito.

  • Duración: 6 semanas
  • Modalidad: 100% Online
  • Proyecto: Repositorio colaborativo publicado con GitHub Pages
Ver detalles Información

9. Introducción a la Ciencia de Datos con Python

Analiza datos reales con Python, pandas y visualizaciones para tomar decisiones basadas en información.

  • Duración: 12 semanas
  • Modalidad: Online guiada
  • Proyecto: Dashboard analítico con datos reales
Ver detalles Información
