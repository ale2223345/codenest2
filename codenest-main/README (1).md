# CodeNest | Tu primer paso, escrito en código

Sitio web institucional de **CodeNest**, una academia de formación práctica en programación para Centroamérica, con bootcamps de 8 a 16 semanas orientados a personas sin experiencia previa.

Proyecto desarrollado para la asignatura **LME901 - Lenguajes de Marcado y Estilo Web** de la **Universidad Don Bosco** (Grupo 2). Esta versión corresponde al **Sprint III**: optimización, diseño responsivo y publicación en un servicio de hosting.
